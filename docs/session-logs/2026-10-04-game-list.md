# Session log: game list without backend (MVP step 2)

Date: 2026-10-04. Result: the app has a working game list stored in the browser; no Supabase yet.

## What was built

- **Logic** (`src/library/library.ts`), written test-first with the `tdd` skill: adding Games (single and one title per line), the five Statuses, automatic start/end dates, Current limit (default 3, adjustable, `Paused` not counted), manual Backlog order with up/down, delete, and the three views with their sort orders. 24 tests, independent of React.
- **Storage** (`src/library/storage.ts`): small async `LibraryStore` interface plus a localStorage implementation (chosen over IndexedDB as the simpler one). Unreadable stored data falls back to an empty Library.
- **UI**: `App` plus `src/components/`. Three columns from 900px width (PC, iPad landscape), tabs below. Touch targets are at least 48px. Light and dark follow the system. Delete asks for confirmation in a dialog. A full Current shows an explanatory message instead of moving the Game.
- `t()` now fills `{placeholders}`; `src/test-setup.ts` now unmounts components after each test.

## Decisions (not in the docs before)

- Dates: moving to `Playing` sets the start date once and keeps it when resuming from `Paused` or picking up a Played Game again; moving to `Finished`/`Dropped` sets the end date; moving to `Playing`/`Paused` clears the end date; back to `Unplayed` clears both.
- A Game that returns to the Backlog (paused, or reopened from Played) goes on top; new Games go to the bottom.
- Move buttons per Status: Unplayed/Paused → Playing, Dropped; Playing → Paused, Finished, Dropped; Finished/Dropped → Playing, Unplayed.
- Lowering the Current limit below the number of Playing Games keeps those Games and only refuses new ones. Limit must be a whole number of at least 1.
- UI wording: Backlog / Aktuell / Gespielt for the views.

## Known gaps

- Data lives only in one browser: the iPad and the PC do not share it until Supabase sync exists. Clearing Safari website data deletes it.
- If stored data is corrupt it is treated as empty and overwritten by the next change.
- Up/down buttons stay visible on the first and last Backlog entry and do nothing there.
- No Copies, search/filter, notes or own rating yet.
