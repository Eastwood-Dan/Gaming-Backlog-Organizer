# Build a PWA instead of a native iOS app

The app is a web app (TypeScript, React, Vite) installed as a PWA on the iPad and used in the browser on the Windows PC. A native iOS app would need a Mac for Xcode, which the owner doesn't have, and a paid Apple Developer account for lasting installs. A PWA runs on both devices from one codebase at no cost. If the app is later published, it can be wrapped for the App Store (e.g. Capacitor), which then needs a cloud Mac and an Apple account.
